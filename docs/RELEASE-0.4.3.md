TailKana 是面向中文用户的 macOS 日文输入法，基于 Fcitx5 macOS 与 Mozc，支持末尾十字轮盘、假名标注、简体中文释义、模糊拼音、中文第三候选及离线 AI 上下文推荐。

下载 `TailKana-0.4.3-arm64.pkg`，适用于 Apple Silicon、macOS 15 或更高版本。安装后打开「应用程序 → TailKana → 启用并切换」；更新后从输入法菜单选择「重新启动输入法」。应用使用临时签名，安装包尚未经过 Apple 开发者签名和公证。

本版修复长输入严重卡顿：停止为重放过程中的每个中间前缀重复生成候选，只预测最终输入。开启纠错、中文候选和释义的本机原生逐键测试：

| 罗马字长度 | 修复前中位数 | 修复后中位数 |
| --- | --- | --- |
| 9–16 | 64.94ms | 13.88ms |
| 17–32 | 251.23ms | 27.65ms |
| 33–46 | 745.54ms | 42.25ms |

最慢一键 1020.39→75.98ms。以上不包含宿主应用、面板绘制或 AI 评分，结果随机器及词句变化。六组原生回归通过；候选、读音和顺序与旧路径对照一致；安装包完成签名、词库、模型和输入源身份校验。

保留 0.4.2 的默认日文／英文、框宽设置，以及自适应字号、自动展开和恢复紧凑布局等功能。

安装包校验值见 `SHA256SUMS.txt`。源码及依赖锁定信息随 v0.4.3 标签公开，许可证见仓库 THIRD_PARTY.md。
